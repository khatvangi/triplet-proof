# Third-party source data (not redistributed)

The position-specific misreading rates are computed from published supplementary data,
which are not copied into this archive. Download them from the publishers and place them
here; the checksums in `SHA256SUMS_primary.txt` identify the exact files used.

- Katoh T, Suga H (2023) Nucleic Acids Res 51:10642-10652, doi:10.1093/nar/gkad707.
  Supplementary data (`gkad707_supplemental_files.zip`; Supplementary Fig. 8 was parsed into
  `../katoh2023_s8_parsed.csv`, included).
- Landerer C, Poehls J, Toth-Petroczy A (2024) Mol Biol Evol 41:msae048,
  doi:10.1093/molbev/msae048. Supplementary data (`msae048_supplementary_data.zip`, from
  Europe PMC PMC10939442; Data S2 and Data S4 are used).

Derived tables used by the paper (`../POSITION_RATES.json`, `../*_position_summary.json`,
`../landerer2024_bootstrap.json`) are included.
